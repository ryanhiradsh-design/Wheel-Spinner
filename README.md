# Wheel Spinner Android App

This is a ready-to-build Android app for the Wheel Spinner. It is designed to work offline and keep saved wheels on the device.

## Build the APK from a phone

1. Upload this folder to a GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Build Wheel Spinner APK**.
4. Tap **Run workflow**.
5. When it finishes, open the completed workflow run.
6. Download the **WheelSpinner-debug-apk** artifact.
7. Extract it and install `app-debug.apk` on your Android phone.

GitHub Actions performs the Android build in the cloud, so Android Studio is not required on your phone.
